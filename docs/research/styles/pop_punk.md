# Поп-панк

Метки: ● первоисточник / ≥3 ист.; ◐ 2 ист.; ○ 1 блог или вывод. Основной источник — Andrew Wade (Neck Deep, A Day To Remember)
в Nail The Mix: настройки с экрана сессии.

## Цепь (Andrew Wade) [P1, P2]

| Блок | Значения | Дов. |
|---|---|---|
| Запись | U 87 → 1176 на входе | ● |
| Инсерт лида | **1176 «All Buttons In»: Input ≈33, Output ≈21, Attack 4, Release 7 (самый быстрый), GR 7–10 дБ** | ● |
| Вокальная шина | де-эссер → SSL-EQ (подъем верха) → мягкий компрессор, **GR 5–6 дБ** в больших припевах → ревер **≈20 % wet** | ● |
| Де-эссер | осторожно: перебор дает «дефект речи»; на бэках де-эссер сильный | ● |
| Бэки | та же 1176-компрессия, HPF, агрессивный тюн | ● |
| **Припевы** | **трипл-трекинг, даблы жестко L/R** | ● [P1, P2, P3] |
| Ганг-вокалы | без ревера, **длинный дилей** создает «большое помещение»; крик + пение + шум бара | ● |

- Joey Sturgis: вокал проходит 2, 3, 4 и больше ступеней компрессии до печати; сатурация на второй ступени [P4]. ◐
- Даблы надо жать так же, как лид, иначе дабл «вылезает» [P5]. ◐
- Жесткая панорама даблов — стандарт; некоторые советуют 10 и 2 часа («прощает больше») [P3]. ◐

## Подписи стиля
- Максимально ровный и яркий голос (1176 all-buttons, GR до 10 дБ + шина 5–6 дБ).
- Ширина за счет перепетых даблов L/R, а не ревера; ревер ~20 %.
- Ганг-вокалы с длинным дилеем вместо ревера.

## Чего нет в палитре
- All-buttons 1176 (характерный перегруз FET): ближайшее — `compressor` 10:1, attack 1 мс + немного `distortion`.
- Трипл-трек: один слой `harmony` с width 1 дает два голоса по краям, лид в центре — по сути то же самое, но голоса синтетические (питч-копия).
