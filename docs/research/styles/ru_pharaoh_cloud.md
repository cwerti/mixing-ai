# Pharaoh и клауд-рэп (Dead Dynasty)

## Что известно
- Жанры: трэп, клауд-рэп, эмо-рэп; один из главных проводников клауд-рэпа в России [H1]. ●
- Продакшен Dead Dynasty (White Punk, Yung Meep, Bright), FrozenGangBeatz [H1]. ●
- *Rule* (2020) и коллаборация с Лободой — «обновленное поп-звучание»; трек «OMEGA» (2024) с Destroy Lonely — «непривычный
  opium-звук» [H1]. ●
- Клауд-рэп как жанр: туманная, «облачная» реверберация, медленная лаконичная читка, мемфис-влияние (общеизвестное описание жанра, ○).
