# EDM-топлайн (вокал в танцевальном треке)

Метки: ● первоисточник / ≥3 ист.; ◐ 2 ист.; ○ 1 блог или вывод. Цифр «от продюсера» не найдено; есть согласие источников по приемам.

| Блок | Значения | Дов. | Ист. |
|---|---|---|---|
| Компрессия | сильная, часто две ступени; OTT/мультибэнд на «блеск» (OTT 50–80 % в смежном hyperpop — `../links.md`) | ◐ | 2 [E1, E2] |
| EQ | яркий: срез низа (HPF 120–200 Гц, бас и кик занимают низ), воздух 10–16 кГц | ○ | вывод (общепоп + E1) |
| **Ревер** | большой hall/plate, **посылом**, **сайдчейн от сухого голоса**: компрессор после ревера, ratio максимум, атака минимальная, релиз по темпу | ● | 3 [E3, E4, E5] |
| Длина ревера | 5-секундные редко нужны; короткие дают «большой» звук без каши; длина должна быть связана с темпом | ◐ | 2 [E1, E6] |
| **Дилей** | 1/4 (или пунктирная 1/8) с сайдчейном: звучит в паузах между фразами | ● | 3 [E7, E4, E5] |
| Несколько посылов | один ревер почти никогда не достаточен: основной ревер + стерео-дилей для ширины + фильтрованный 1/4 | ◐ | 2 [E4, E8] |
| Тюн | плотный, ровный (вокал-«инструмент»), часто retune быстрый | ○ | вывод |
| Ширина | стерео-дилей, бэки/даблы широко | ◐ | 2 |

## Подписи стиля
- «Облако» ревера и дилея, которое появляется только в паузах (дакинг) — голос при этом сухой и громкий.
- Плотный, яркий, сжатый голос без провалов.

## Ошибки
- Сайдчейн прямо в ревер (вход) — ревер звучит во время слова и пропадает в паузах, наоборот [E5].
- Переизбыток компрессии — тонкий, раздавленный микс [E1].

## Чего нет в палитре
- **Дакинг эффектов от сухого голоса** — ключевой прием стиля, у нас нет. Без него большой ревер = каша.
- Второй дилей / второй ревер.
