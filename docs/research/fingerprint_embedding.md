# Выученный эмбеддинг отпечатка эффекта

Дата: 2026-11-03. Ветка `feat/chain-benchmark`. Код: `app/eval/fingerprint_embedding.py`,
`scripts/train_fingerprint_embedding.py`. Данные и отчет: `data/runs/fingerprint/embedding/`
(`effects/*.npz`, `report.json`, `generate.log`, `train.log`), модель — `embedder.pt` (обучена на всех, кроме
22 режимов по умолчанию).

Вопрос: может ли выученное расстояние между эффектами предсказывать разницу на слух лучше, чем ручное
`fingerprint_distance`? На 22 режимах Supermassive по умолчанию у ручного Spearman было 0.72
(`effect_fingerprint.md`).

## Набор

Всего 472 эффекта:
- 300 случайных цепочек нашего DSP (ревер с RT60 или Freeverb, дилей, хорус, ревер+дилей, хорус+ревер) через
  `DSPEngine.apply_chain`;
- 150 случайных настроек Supermassive (режим, mix, delay_ms с перекосом к 0 и коротким, feedback, density,
  width, cuts, модуляция, warp);
- 22 режима Supermassive по умолчанию.

На каждый эффект есть три представления:
- отпечаток с текущей (на момент генерации) версией `effect_fingerprint.py`, параллельно его правил другой форк;
- карта отклика на импульс: Mid/Side × 7 полос × 21 логарифмическое окно до 8 с;
- log-mel мокрого рендера склейки трех сухих вокалов по 6 с (Whiptails, mckay, wessel).

Цель для пары — симметричная log-mel ошибка, как `logmel_db` в `real_pairs.py`, с кадрами, усредненными по 4.
Медиана цели 7.6 дБ, 90-й перцентиль 12.7 дБ.

Время: DSP — 3.4 с на эффект. Supermassive — около 190 с на эффект при 8 процессах (один процесс — около
40 с). Свежая загрузка плагина на каждый рендер, параллельность масштабируется плохо. Генерация заняла
около 70 мин.

## Результат

Модель — MLP 128-128-16, вход — признаки плюс карта. Цель обучения — евклидово расстояние эмбеддингов равно
log-mel цели (smooth L1). 300 эпох, 3 seed. Baseline — взвешенная L2 по признакам (NNLS по d²).

| Сплит (тестовые пары) | ручное | взвеш. L2 | эмбеддинг | ранг соседа: ручн. / L2 / эмб. |
|---|---|---|---|---|
| случайные 30 % эффектов (9045) | 0.539 | 0.691 | **0.930 ± 0.002** | 11.7 / 9.3 / 5.6 |
| отложенные режимы SM целиком (703) | 0.633 | 0.656 | **0.890 ± 0.005** | 6.2 / 5.3 / 5.7 |
| 22 режима SM по умолчанию (231) | 0.763 | 0.772 | **0.874 ± 0.034** | 2.05 / 2.27 / 1.92 |

Отложенные режимы: Andromeda, Aquarius, Cirrus Minor, Gemini, Large Magellanic Cloud, Lyra. Ручное расстояние
на 22 режимах здесь 0.76, а не 0.72: отпечаток уже переделан (окна плотности эха, RT60), рендер другой
(склейка трех сухих).

Что дает вход сети (2 seed, 200 эпох):

| Сплит | только признаки | только карта | оба | MAE расстояния (оба) |
|---|---|---|---|---|
| случайные 30 % | 0.923 | 0.915 | 0.935 | 1.12 дБ |
| отложенные режимы | 0.864 | 0.869 | 0.891 | 1.69 дБ |
| 22 по умолчанию | 0.816 | 0.799 | 0.898 | 1.37 дБ |
| **обучение только на DSP → тест на Supermassive** | 0.426 | 0.583 | 0.442 | **10.6 дБ** |

## Выводы

1. **Выученная метрика заметно лучше ручной.** Spearman 0.87–0.93 против 0.54–0.76. Расстояние предсказывается с
   ошибкой 1.1–1.7 дБ log-mel при медиане 7.6 дБ. Основной выигрыш дает уже нелинейная метрика над ручными
   признаками (0.82–0.92). Карта отклика добавляет +0.01…+0.08, больше всего на режимах по умолчанию.
2. **Перенос на новые режимы того же плагина работает** (0.89). Если режимы плагина есть в обучении, незнакомый
   режим описывается хорошо.
3. **Перенос на незнакомое семейство плагинов не работает.** При обучении только на нашем DSP на Supermassive
   получается 0.43–0.58 и ошибка 10.6 дБ. Ручные признаки здесь не лучше (ручное расстояние 0.54–0.76 на
   смешанных парах). Это прямой аргумент за «зоопарк»: в обучении нужны примеры от каждого семейства плагинов
   или профилирование плагина пользователя с дообучением.
4. **Ранг ближайшего соседа улучшается слабее, чем Spearman.** На отложенных режимах взвешенная L2 даже лучше
   (5.3 против 5.7). Глобальный порядок пар эмбеддинг ловит хорошо, а тонкое «кто ближе всех» — хуже. Для
   выбора плагина или режима в адаптере это главное, туда нужна ранжирующая функция потерь (triplet / listwise)
   по ближайшим парам.

## Ограничения

- Цель — log-mel на одном наборе из трех сухих вокалов (склейка 18 с). Это не слуховая оценка. Разница уровня
  мокрого (mix) входит в цель наравне с характером хвоста.
- Тест 22 режимов по умолчанию — 231 пара, σ между seed 0.034. Разница с ручным (+0.11) больше шума, но
  выборка маленькая.
- В Supermassive-части только один плагин. Перенос «на чужой ревер» проверен только в одну сторону
  (DSP → SM), и результат отрицательный.
- Отпечатки сняты версией `effect_fingerprint.py` с незакоммиченными правками другого форка. После их коммита
  набор надо пересчитать: генерация хранит сырые отпечатки, а вектор считается при обучении. Если ключи
  `FINGERPRINT_SCALES` не поменялись, достаточно `train`.

## Ранжирующая функция потерь (2026-11-03)

`train --loss rank`: регрессия расстояния плюс listwise (ListNet по строкам матрицы): распределение
softmax(−d/τ) по обучающим эффектам для каждого якоря должно совпасть с предсказанным. Полный батч (~300
эффектов), 2000 шагов, 3 seed. Нормировка входа теперь с нижней границей σ (`STD_FLOOR = 0.25`, см. ниже).
Отчеты: `data/runs/fingerprint/embedding/grid/report_t{τ}_w{вес}.json`.

Spearman / ранг ближайшего соседа (0 — совпал с ближайшим по звуку):

| Настройка | случайные 30 % | отложенные режимы SM | 22 по умолчанию |
|---|---|---|---|
| регрессия (прежняя, без нижней границы σ) | 0.930 / 5.62 | 0.890 / 5.71 | 0.874 / 1.92 |
| rank τ 0.5, вес 0.3 | 0.935 / 5.11 | 0.876 / **4.56** | 0.845 / 1.82 |
| rank τ 1, вес 0.3 | 0.935 / 5.90 | 0.884 / 4.98 | 0.855 / 1.55 |
| rank τ 1, вес 3 | 0.936 / 5.55 | 0.886 / 5.28 | 0.846 / 1.64 |
| **rank τ 2, вес 3** | **0.937 / 5.62** | 0.878 / 4.64 | **0.866 / 1.36** |
| rank τ 2, вес 1 | 0.936 / 6.02 | 0.884 / 4.96 | 0.849 / 1.47 |

(остальные точки сетки — между ними). Ранжирующий член улучшает ранг соседа на отложенных режимах
(5.7 → 4.6–5.3) и на 22 режимах по умолчанию (1.9 → 1.4–2.0), Spearman при этом в пределах шума между seed
(σ 0.01–0.05). Выбрана настройка τ 2, вес 3: ранг не хуже регрессии ни на одном сплите. Улучшение ранга
небольшое — до «выбирает ближайший режим» далеко (4.6 из 37 отложенных эффектов).

Повторить регрессию с той же нижней границей σ не успел: прогон остановлен системой из-за нехватки памяти
(см. «Проблемы»), поэтому строка регрессии — со старой нормировкой.

## Адаптер: подбор режима и ручек Supermassive по отпечатку (2026-11-03)

Код: `app/eval/plugin_adapter.py`, `scripts/adapter_search.py`. Данные: `data/runs/fingerprint/embedding/adapter/`
(`results_seed0.jsonl`, `summary_seed0.json`, `run_seed0.log`, `check_fast.json`).

Схема: цель — отпечаток эффекта (из набора). Суррогат «режим + 10 ручек → вектор» (MLP, обучен на ~170
эффектах Supermassive набора) оценивает все 22 режима, два лучших идут в CMA-ES по честным рендерам
(3 поколения × 8, итого 48 рендеров на цель). Две цели поиска: выученный эмбеддинг (rank τ 2, вес 3,
обучен без целей) и ручное `fingerprint_distance`. Итог — log-mel мокрого рендера найденной настройки против
целевого на тех же сухих вокалах.

**Быстрый отпечаток.** Полный `fingerprint()` — 5–6 рендеров, каждый на свежем экземпляре. Supermassive при
большой плотности рендерит примерно в реальном времени (28 с сигнала — 25 с), поэтому все тестовые сигналы
склеены в один вход ~22 с и рендерятся одним экземпляром: ~14 с на точку при 3 процессах, ~6–7 с на точку
пропускной способности при 8–9. Расхождение с полным отпечатком (18 точек Supermassive): ручное расстояние
медиана 0.29, максимум 1.3 — при медиане расстояния до ближайшего другого эффекта 1.03. Крупные расхождения
только у длинных дилеев (900 мс × feedback 80 %): хвост не помещается в 8 с, а полный отпечаток продлевает
окно до 24 с.

**Нижняя граница σ.** Первая проверка дала расстояние эмбеддинга быстрый↔полный 195 (!). Причина —
`compression_db`: в наборе почти постоянный (σ 0.001), и разница −0.01 дБ после нормировки давала z ≈ −10.
Теперь σ не меньше 0.25 (`input_stats`), все модели сетки обучены так.

### Результат: 10 целей — случайные настройки Supermassive (seed 0)

log-mel, дБ (меньше — лучше), среднее / медиана:

| Способ | log-mel |
|---|---|
| случайная настройка SM (5 на цель) | 8.70 / 9.29 (лучшая из 5 — 4.72) |
| только суррогат, без рендеров: эмбеддинг / ручное | 4.55 / 4.16 |
| ближайший эффект SM из набора: по эмбеддингу / по ручному | 3.72 / 5.41 |
| лучший эффект SM из набора по самому log-mel (потолок «выбрать из готовых») | 3.12 |
| **адаптер, цель — эмбеддинг** | **3.61 / 2.73** |
| **адаптер, цель — ручное расстояние** | **2.73 / 2.57** |

- Адаптер с ручной целью лучше потолка «выбрать из готовых» (2.73 против 3.12): подбор ручек находит
  настройки ближе, чем любой из 170 готовых эффектов.
- Честные рендеры дают −1…−1.4 дБ к одному суррогату.
- **Как цель поиска ручное расстояние лучше эмбеддинга** (2.73 против 3.61; на 6 целях из 10 ручное лучше на 0.5–3.1 дБ,
  на 4 — равно в пределах 0.06 дБ, хуже — ни разу). При этом **для выбора из готовых эмбеддинг гораздо лучше ручного** (3.72 против 5.41). Похоже,
  CMA-ES находит точки, где эмбеддинг близок к цели, а звук — нет: сеть, обученная на ~450 эффектах, вне их
  распределения обманывается, ручные признаки — нет. Для поиска эмбеддинг нужен с регуляризацией к ручному
  или обученный на точках самого поиска.
- **Режим угадан в 2 из 10 случаев** при обеих целях; истинный режим в двух лучших по суррогату — 3/10
  (эмбеддинг), 2/10 (ручное). Но ошибка режима обходится недорого: целевые ручки с найденным режимом дают
  2.8–3.4 дБ. Режимы Supermassive во многом взаимозаменяемы при подходящих ручках, «угадать режим» — не та
  цель; цель — звук.

### Цели — эффекты нашего DSP (DSP → Supermassive): не досчитаны

Прогон остановлен системой из-за нехватки памяти на 11-й цели (первой DSP), до DSP-целей дело не дошло.
Скрипт возобновляется с места остановки (`results_seed0.jsonl`): `python scripts/adapter_search.py
--targets-sm 10 --targets-dsp 5 --top-modes 2 --generations 3 --popsize 8 --random 5 --tau 2 --rank-weight 3
--workers 8 --seed 0` (эмбеддинг переобучится с тем же seed — те же цели, ~4 мин).
По короткой проверке на одной DSP-цели (seed 99, 2 рендера) результаты 6.6–8.4 дБ против 10.0 у случайной
настройки и 5.0 у лучшего готового эффекта SM — главный кейс заметно труднее.

## Что дальше

- Досчитать DSP → SM (главный кейс «референс сделан другим плагином»).
- Эмбеддинг для поиска: смесь с ручным расстоянием или дообучение на точках самого поиска (hard negatives),
  чтобы CMA-ES не находил «обманные» точки.
- Второй сторонний плагин в зоопарке (Dragonfly / OrilRiver / TAL-Reverb). Проверить перенос SM → новый плагин
  и DSP+SM → новый плагин.
- Склеить с форком слепой оценки: эмбеддинг как пространство, в котором сравниваются оценка по референсу и
  настоящий эффект.
