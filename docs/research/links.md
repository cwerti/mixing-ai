## 2. Треки madk1d для прослушивания и референса

Искать на Яндекс Музыке / Spotify / Apple Music (официальные ссылки не найдены):
https://music.yandex.ru/search?text=madk1d · https://open.spotify.com/search/madk1d

| Трек | Что проверить на слух |
|---|---|
| madk1d, LILCAK3 — «КАТЮХА» | ранний период, вероятнее всего жесткий тюн / хайпер-поп |
| madk1d — «Так по***» (sexyswag, 2025) | ретро-2010: возможно мягкий тюн, близкий сухой вокал |
| madk1d, Тёмный принц — «Ты че обиделась» | два голоса, брать сольный кусок |
| трек с «Он сказал поехали!» (2024) | выбрать с самым голым битом |
| madk1d, greyrock, tewiq — «Martine Rose» | несколько вокалистов |

Стиль менялся по альбомам (трэп/хайпер-поп → «рок» → ретро-2010), поэтому «как у madk1d» лучше
привязывать к конкретному треку. Для жесткого rage-эталона: CUPSIZE, LILCAK3, 9mice.
