# Модель v5: реалистичный генератор, чистый пул, обучение без балансировки классов

Дата: 2026-10-30. Чекпоинт: `data/models/v5/best_model.pth` (эпоха 31 из 35), рядом лежат `best_model.calibration.json`
(ошибка параметров для шага CMA-ES, `scripts/calibrate_prior.py`) и `best_model.platt.json` (Platt по плагину).
v4 не тронут. Датасет: `data/processed/dataset_v4`, старые датасеты на месте. Лог обучения: `data/models/train_v5.log`,
этапы и время: `data/runs/overnight_v5/stages.log`. Сравнение: `scripts/compare_models.py`, сырые результаты в
`data/runs/model_v5/` (`results.json`, `report.md`, логиты `*.npz`, `real_pairs_v4.jsonl` и `real_pairs_v5.jsonl`).
Каталог `data/runs/` в `.gitignore`.

## Коротко

1. **Ложных включений chorus и distortion стало в 2–3 раза меньше на всех наборах**, а уверенных ложных включений
   (p > 0.9, оптимизатор их не выключает) — в 3–7 раз меньше. На пресет-подобных референсах с даблами v4 включал
   distortion в 64 % пар и stereo_enhancer в 68 %, v5 — в 23 % и 4 %.
2. **Платим полнотой редких эффектов.** Модель выучила реальную редкость chorus/distortion: на парах с цепочками
   генератора v3 (50 % на эффект) полнота distortion упала с 0.81 до 0.54, chorus — с 0.82 до 0.61. На парах с
   реалистичным распределением F1 у v5 выше (distortion 0.63 против 0.55, chorus 0.48 против 0.37).
3. **Компрессор v5 включает почти всегда** (89 % в данных, FPR 0.85–0.88 на всех наборах пар). Это следствие
   реалистичного prior, а не ошибка, но для `MODEL_KEEP_PROB` компрессор теперь «прибит» (p > 0.9 у половины
   пар без компрессора).
4. **На 8 реальных парах режим model без подбора у v5 не лучше v4**: на Whiptails v5 больше не предсказывает
   distortion + chorus (главная жалоба на v4), но и реверб со стерео тоже не предсказывает. На ленточной паре
   Ronnie (cross) v5 включает тюн, сатурацию и экситер, ошибка F0 растет 0.4 → 15 ц. Средние по 16 кейсам:
   style 1.68 → 1.75, logmel 2.69 → 2.81 дБ. Выборка маленькая (6 из 8 пар — один тюн одной песни).
5. **Platt для v5 сдвигает пороги chorus/distortion до сырых 0.85–0.90** и режет полноту еще сильнее. Для решения
   «включать ли» у v5 разумнее оставить сырой порог 0.5, а Platt применять к вероятностям для `MODEL_KEEP_PROB`.

### Параметры

- **Слабые настройки.** Треть включенных distortion — почти чистая сатурация (drive 0–4 дБ при подмесе 22–25 %),
  треть хорусов — легкие (mix 5–11 %, малая глубина).
- **Диапазоны:** `distortion.drive_db` 4–20 → **0–20 дБ**, `chorus.mix` 0.12–0.45 → **0.05–0.45**
  (`DATAGEN_PLUGINS`). Размерности выхода модели (`MODEL_PLUGINS`, `PARAM_LAYOUT`) не менялись.
- **Prior по рецептам** (70 % сэмплов, остальные 30 % равномерно по всему диапазону, чтобы регрессия не стягивалась
  к prior): жесткий тюн (speed 0.8–1.0) в новой школе, natural (0.2–0.65) в остальных; компрессор ratio 2.5–5,
  attack 10–30 мс, release 170–330 мс; реверб большой и темный; дилей синхронизирован с темпом (1/4, 1/8, 1/16
  при 120–165 BPM).
- **Даблы и гармонии в референсе** (рендер-плагин `harmony`, модель его не предсказывает): стерео-даблы ±85–100 %,
  −3…−12 дБ; моно-дабл −10…−15 дБ; гармонии +3/+4/+5/+7/−5/±12 полутонов, ±75–90 %, −6…−10 дБ; иногда два слоя.
  Слои встают перед реверб/дилеем (`RENDER_ORDER`), в метку не входят и пишутся в отдельное поле `ref_layers`.

### Совместимость

- Нормализованные drive и chorus.mix у v4 теперь означают другое физическое значение. Чекпоинт v5 хранит
  `param_ranges`, а для чекпоинтов без этого ключа `remap_param_vector` пересчитывает два параметра из
  `LEGACY_PARAM_RANGES` в текущие диапазоны (`MixingAIMLPipeline`, GUI, `scripts/process_vocal.py`). v4 рендерит
  тот же физический drive, что и раньше.
- Защитные пределы, заданные в нормализованных единицах, пересчитаны на те же физические значения:
  `DSPEngine.clamp_normalized_params` (drive 0.40 → 0.52, chorus.mix 0.20 → 0.34) и лимит режима model в
  `app/ml/pipeline.py` (drive 0.35 → 0.48).
- `_generate_balanced_random_config` не изменен: его используют бенчмарк и калибровочные скрипты. Но из-за новых
  диапазонов его нормализованный drive теперь рендерится слабее (0–20 дБ вместо 4–20).
- В оптимизаторе (`app/mixing/chain_optimizer.py`, не менялся) distortion при drive 0 почти не слышен, поэтому
  посылка «включенный плагин всегда слышен» для него больше не выполняется: CMA-ES может «выкрутить» сатурацию.

### Обучение

Рецепт v4: `scripts/train_ml.py`, 35 эпох, patience 8, batch 32, lr 1e-3 cosine, выбор по `MAE − 0.15·F1`.
Одно отличие — **`--pos-weight none`**. В v4 BCE взвешивалась как N_neg/N_pos (до 3x). При реалистичных частотах
такая балансировка вернула бы chorus эффективную априорную частоту около 0.4 и с ней ложные включения.
Ранняя остановка не сработала, лучшая эпоха 31 (val macro-F1 0.841, MAE 0.100), 166 с на эпоху.

## Выводы

1. Цель переобучения по ложным включениям достигнута: реалистичные частоты, даблы в референсе и обучение без
   балансировки классов в 2–3 раза снизили FPR chorus/distortion и почти убрали ложный stereo_enhancer и реверб
   на даблах. Калибровкой v4 этого не получить: даже после Platt у v4 на preset_layers ложный distortion в 55 %
   пар, у v5 без всякой калибровки — в 23 %.
2. Цена — полнота редких эффектов и почти безусловный компрессор. Если оптимизатор и дальше включает
   chorus/distortion по уверенности модели (`> 0.8`), у v5 это будет происходить редко. Это правильно для лид-пресетов
   и плохо для hyperpop/rage-референсов.
3. На реальных парах v5 пока не выигрывает. Главная ошибка обеих моделей — пропуск реверба, стерео и тюна на
   Whiptails и тюна на oxeye — не лечится частотами генератора: там реальный реверб и тюнер не похожи на рендер
   Freeverb/PSOLA.
4. Рекомендации:
   - Для решения «включать ли» оставить у v5 сырой порог 0.5. Platt v5 подключать только к `MODEL_KEEP_PROB`
     (удержание в оптимизаторе) вместе с усреднением логитов по 4 окнам.
   - Для компрессора не опираться на модель в `MODEL_KEEP_PROB`: при частоте 89 % ее уверенность — это prior.
   - Следующий шаг по данным: реальные даблы из Cambridge (стемы `*DT*`) вместо сдвинутых копий и реверб с другим
     характером (HPF реверба, predelay), иначе сдвиг домена на реальном реверберированном вокале останется.
   - Набор реальных пар нужно расширить: 8 пар из 3 песен (6 — один тюн) не дают отличить модели.

## Воспроизведение

```bash
python scripts/prepare_dataset.py --max-samples 30000 --seed 0 --cross-ratio 1.0 --output-dir data/processed/dataset_v4
python scripts/train_ml.py --dataset-dir data/processed/dataset_v4 --save-dir data/models/v5 --epochs 35 --patience 8 --pos-weight none
python scripts/calibrate_prior.py --model-path data/models/v5/best_model.pth --dataset-dir data/processed/dataset_v4
python scripts/compare_models.py val
python scripts/compare_models.py pairs --set bench_balanced --n 300 --seed 1
python scripts/compare_models.py pairs --set bench_realistic --n 300 --seed 3
python scripts/compare_models.py pairs --set preset --n 200 --seed 2
python scripts/compare_models.py pairs --set preset_layers --n 200 --seed 4
python scripts/compare_models.py report --save-platt v5
python scripts/real_pairs.py --model-path data/models/v5/best_model.pth --modes model --out data/runs/model_v5/real_pairs_v5.jsonl \
    --audio-tmp data/runs/model_v5/real_audio_v5 --listen-dir data/processed/real_pairs_v5/v5
```

Время: датасет 1 ч 36 мин (20 ядер), обучение 1 ч 38 мин (RTX 5070), сравнение около 12 мин.
