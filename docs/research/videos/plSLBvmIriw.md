## Graillon 3 (free), дефолт (кадр 07:35)

| Параметр | Значение по умолчанию | Что делает (по словам автора) |
|---|---|---|
| Pitch engine | G3 (есть G2 и I2) | G3 — новая версия, «звучит лучше»; **I2 — очень мягкая коррекция**, сохраняет оригинал |
| Correction Amount | 100% | — |
| **Smooth** | 5.0 ms | время перехода: меньше = резче (хард-тюн), больше = плавнее |
| **Inertia** | 20% | 0% «самое естественное»; 50–100% даёт странный «плавающий» эффект |
| **Snap Min** | 0.00 st | 0 = агрессивнее всего; выше = мягче |
| **Snap Max** | 8.00 st | на сколько далеко подтягиваются фальшивые ноты |
| Pitch-shift / Formants | 0 / 100% | сдвиг высоты и форманты, «для фана» |
| Comp / Gate / Quantize / Reduce | 0% / −60 dB / 1.0 smp / 23.0 bit | встроенные эффекты (lo-fi через Quantize/Reduce) |
| Wet / Dry | 0 dB / −inf | слушать только обработанный сигнал |
| Low Cut | Off | — |

## Как он настраивает
- Главное — четыре ручки секции Correction: Smooth, Inertia, Snap Min, Snap Max (13:35, 16:14).
- Хард-тюн: Smooth вниз, Snap Min 0. Естественно: Smooth вверх, Inertia 0%, Snap Min чуть выше (10:37–13:23).
- Предупреждение: при слишком сильном сглаживании вокал перестаёт держаться на ноте, коррекции почти нет (15:51–16:03).

## Что важно для нас
- Связь с нашим `pitch_corrector.speed`: Smooth Graillon ≈ обратная величина speed (5 мс ≈ жёсткий тюн, speed→1.0).
- Inertia и Snap — параметры, которых у нас нет; хард-тюн новой школы — это Smooth ≈ 0–5 мс, Snap Min 0.
