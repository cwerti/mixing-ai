# Servida Music — The ULTIMATE Guide To Mixing Rap Vocals!

- Ссылка: https://www.youtube.com/watch?v=8g7ituDRJa4
- Канал: Servida Music (Brian), EN, ~9:20, рэп (сингл «Villain»). Основные плагины FabFilter, к каждому назван стоковый аналог FL.
- Источник текста: автосубтитры YouTube; кадры не разбирались по ручкам (числовых настроек автор почти не даёт).

## Подготовка
- Акустика важнее плагинов: панели на стену за мики и в углу записи, одеяла/вокальный экран при малом бюджете; убрать посторонний шум (00:29–01:40).
- Склеить лучшие дубли (comp), **вырезать вдохи** (02:00–02:30).

## Цепочка лида (куплет, «чистый» вариант)

| # | Плагин (стоковый аналог) | Настройки | Время | Источник |
|---|---|---|---|---|
| 1 | Pro-Q (Fruity Parametric EQ) — вычитающий | свип узкой полосой, резонансы вниз **~3 дБ**, без подъёмов; HPF: «резать, пока не станет слишком, потом немного назад», **с битом** | 02:33–04:09 | речь |
| 2 | Pro-C (Fruity Compressor) | пресет для вокала, подстраивает только threshold | 04:09–04:50 | речь |
| 2b | (опц.) второй компрессор | «два мягких лучше, чем один сильный» | 05:10–05:20 | речь |
| 3 | Де-эссер (Maximus, пресет) | по слуху | 05:20–05:40 | речь |
| 4 | EQ ещё раз | ещё срез низа + подъём верха, «чтобы был поверх бита» | 05:40–06:04 | речь |

## Припев («креативный»)
EQ (срез низа) → компрессор → сатурация (немного «грязи») → EQ (убрать лишнее после сатурации) → Microshift (шире) → немного delay → EQ с автоматизацией. 06:22–07:10, речь.
- Питч-даун слой: EQ → хорус → компрессия. 07:13.

## Адлибы
Saturn (сатурация) → сильная компрессия → EQ (убрать «грязь» низа) → delay + reverb. 07:31–07:42.
- Сайдчейн бита от вокала хука: при вокале проседает часть бита (на отдельном треке), «вокал садится в микс». 07:42–08:08.
