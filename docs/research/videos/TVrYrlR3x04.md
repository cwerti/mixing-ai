## Уровни и порядок работы
- Порог компрессора выбирает по Wave Candy: где «чаще всего» держится уровень вокала (у него около −9 дБ) (12:40–13:30).
- **Пиковый уровень вокала после цепи около −6 дБ**; дубли, бэки и адлибы на **−12…−15 дБ** (04:48, 19:35).
- Сначала всё настраивать на сухом вокале без бита, бит включать только для реверба и дилея (04:25).

## Адлибы
- Копия той же цепи; на EQ #2 полосовой фильтр (пресет «20 Hz–18 kHz cut», «коробка»), реверб сильно больше, громкость −12…−15 дБ (18:40–19:50).

## Почему так
- Порядок: тюн → гейт (убрать шум, который вытянул тюн) → EQ-срез → EQ-подъём → компрессор → де-эссер → реверб → дилей (01:03–01:38).
- Срез баса: вокал не должен сталкиваться с 808 (12:00).
